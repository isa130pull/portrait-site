コンチェキ プライバシーポリシー

最終更新日: 2026年8月26日

かわぐち（isa130pull）（以下「運営者」といいます）は、スマートフォンアプリ「コンチェキ」（以下「本アプリ」といいます）におけるユーザーのプライバシーを尊重し、以下のとおり個人情報を適切に取り扱います。

1. 取得する情報

本アプリでは、以下の情報を取得します。

  1. ユーザー識別子: 認証サービス（Firebase Authentication）が発行する UID、およびアカウント連携に使用する認証プロバイダのユーザー識別子
  2. アカウント情報: Google アカウントとの連携をユーザーが選択した場合に、Google から提供される氏名およびメールアドレス。本人認証とアカウント連携にのみ使用し、公開プロフィール、ランキング表示、広告には使用しません。Apple アカウントとの連携では氏名およびメールアドレスを要求しません。
  3. 位置情報: チェックインの正当性確認のために、QR コード読み取り時にのみ取得する端末の位置情報(GPS)
  4. 利用ログ: チェックイン履歴、ポイント残高、ガチャ履歴、所持アバター
  5. 端末情報: OS バージョン、端末モデル、アプリのバージョン、言語設定、アプリインスタンス識別子
  6. 利用解析情報: アプリ内の画面遷移、機能の利用頻度等(Firebase Analytics により自動取得)
  7. チェキ情報: チェキ帳機能に登録されるチェキ画像および付随情報（撮影日、店舗、メモ等）。取り扱いは取得経路により次のとおり異なります。
    • ユーザーが端末のカメラロール等から手動で登録したチェキ: 画像および付随情報は端末内（アプリ内のローカルデータベースおよびアプリ専用領域）にのみ保存され、運営者のサーバーには送信されません。運営者はこれらを取得しません。
    • 店舗から送付されたチェキ: 店舗（管理者）が送付した画像および付随情報（送信元キャスト、店舗、撮影日、メモ）は、運営者が利用する Firebase（Cloud Storage / Firestore）に保持され、ユーザー端末がこれをダウンロードして端末内にも保存します。
  8. 購入履歴: アプリ内課金（5 連召喚）を購入した際の商品種別、支払金額、購入日時、および購入時点でアイコンに設定していたキャストの情報。決済処理は Apple / Google の各ストアが行い、運営者がクレジットカード番号等の決済情報を取得することはありません。
  9. お問い合わせ情報: アプリ内フォームから送信された件名、本文、任意で入力された返信先メールアドレス、および対応に必要なユーザー識別子、OS、アプリのバージョン、問い合わせ ID

Google アカウント連携時およびユーザーが問い合わせの返信先として任意に入力した場合を除き、本アプリは氏名およびメールアドレスを取得しません。また、電話番号、住所、生年月日、クレジットカード情報は取得しません。

2. 利用目的

取得した情報は以下の目的に利用します。

  1. 本人認証、アカウント連携および本アプリの機能提供（チェックイン、ポイント付与、ガチャ、アバター管理）
  2. チェックインの正当性確認（位置情報）
  3. アプリ内課金の購入内容の記録、付与の管理（二重付与・未付与の防止）および購入に関するお問い合わせへの対応（購入履歴）
  4. 不正利用の検知および防止
  5. 本アプリの品質改善および新機能の検討
  6. ユーザーからのお問い合わせの受付、運営者への通知および回答
  7. 法令に基づく対応

3. 第三者提供

運営者は、以下の場合を除き、取得した情報を第三者に提供しません。

  1. 法令に基づく場合
  2. 人の生命、身体または財産の保護のために必要であり、本人の同意を得ることが困難な場合
  3. 第 4 項に定める業務委託先に、利用目的の達成に必要な範囲で提供する場合

4. 業務委託（外部サービスの利用）

運営者は、本アプリの提供にあたり、以下の外部サービスを利用しています。各サービスのプライバシーポリシーは各社のページをご確認ください。

サービス名 提供事業者 利用目的
Google Sign-In / Firebase Authentication / Firestore / Cloud Storage / Cloud Messaging / Analytics / Crashlytics Google LLC Google アカウント連携、認証、データ保存、店舗からのチェキ送付（画像保管）、通知配信、利用解析、不具合検知

  • Microsoft: https://privacy.microsoft.com/ja-jp/privacystatement

5. Cookie および同等の技術

本アプリは Web ブラウザを介した Cookie の発行を行いません。上記第 4 項の外部サービスは、認証、通知配信、利用解析および不具合検知のため、アプリインスタンス識別子やデバイストークン等を保存・参照する場合があります。本アプリは広告識別子（IDFA / AAID）を取得せず、他社のアプリやウェブサイトを横断したトラッキングを行いません。

6. 開示・訂正・削除

ユーザーは、運営者に対して、自身の個人情報の開示、訂正、利用停止、削除を求めることができます。本アプリ内の設定画面からアカウント削除を行うことで、保存された情報は速やかに削除されます。これに加えて手続を希望する場合は、第 9 項のお問い合わせ先までご連絡ください。

7. 安全管理

運営者は、取得した情報の漏えい、滅失、改ざんを防止するため、合理的な安全管理措置を講じます。

8. ポリシーの変更

本ポリシーは、必要に応じて改定されることがあります。改定後のポリシーは、本ページに掲載した時点で効力を生じます。重要な変更がある場合は、本アプリ内で通知します。

10. 外部送信に関する公表（電気通信事業法第 27 条の 12）

本アプリは、ユーザーの利便性向上およびサービスの品質改善のため、ユーザーの端末から外部の事業者へ次の情報を送信しています。

10.1 Firebase Authentication / Firestore / Cloud Storage / Cloud Messaging（Google LLC）

  • 送信される情報: UID、認証トークン、認証プロバイダのユーザー識別子、Google アカウント連携時の氏名およびメールアドレス、アプリ内データ（ポイント残高、チェックイン履歴、所持アバター）、アプリ内課金の購入記録（商品種別、支払金額、購入日時、購入時点でアイコンに設定していたキャスト）、デバイストークン、店舗から送付されたチェキの画像および付随情報（送信元キャスト、店舗、撮影日、メモ）
  • 送信目的: ユーザー認証、データの永続化、店舗からのチェキ送付、プッシュ通知配信
  • プライバシーポリシー: https://policies.google.com/privacy
  • 設定変更方法: アプリ内のアカウント削除機能、または端末の通知設定からプッシュ通知をオフにできます
  • 注: ユーザーが手動で登録したチェキの画像および付随情報は端末内にのみ保存され、外部へ送信されません。

10.2 Firebase Analytics（Google LLC）

  • 送信される情報: アプリ内イベント（画面表示、ボタン押下、チェックイン回数、ガチャ実行回数）、端末情報（OS バージョン、端末モデル、言語設定）、アプリインスタンス識別子
  • 送信目的: アプリの利用状況の解析、品質改善
  • プライバシーポリシー: https://policies.google.com/privacy
  • 設定変更方法: アプリ内のアカウント削除機能により、以後の送信を停止できます

10.3 Firebase Crashlytics（Google LLC）

  • 送信される情報: アプリのクラッシュ発生時のスタックトレース、端末情報、アプリのバージョン
  • 送信目的: アプリの不具合検知および修正
  • 識別情報の取扱い: UID、氏名、メールアドレス、表示名その他のユーザー識別情報をクラッシュレポートに設定または送信しません。独自に記録するエラーは、固定のイベント名、例外の型およびスタックトレースに限定します
  • プライバシーポリシー: https://policies.google.com/privacy

10.4 PlayFab（Microsoft Corporation）

  • 送信される情報: 匿名 UID に紐づく PlayFab タイトルプレイヤー、ランキング集計用の統計値（トロフィー獲得数・月間チャレンジ値）、ランキング行に表示するアバター ID
  • 送信目的: 全国ランキング（リーダーボード）の集計・表示
  • プライバシーポリシー: https://privacy.microsoft.com/ja-jp/privacystatement

10.5 Discord（Discord Inc.）

  • 送信される情報: アプリ内フォームから送信されたお問い合わせの件名・本文・任意の返信先メールアドレス、Firebase UID、OS、アプリのバージョン、問い合わせ ID
  • 送信目的: 運営者専用の非公開チャンネルへの問い合わせ通知および問い合わせ対応
  • プライバシーポリシー: https://discord.com/privacy/privacypolicy
  • 設定変更方法: お問い合わせフォームを送信しない場合、Discord への送信は行われません。返信先メールアドレスの入力は任意です

10.6 公表の更新

本公表内容は、外部送信先または送信内容に変更があった場合、速やかに更新します。
