ヒトコマ プライバシーポリシー

最終更新日: 2026年8月4日

本プライバシーポリシーは、iOS アプリ「ヒトコマ」（以下「本アプリ」）における利用者情報の取り扱いについて定めるものです。

1. 基本方針

本アプリは、写真の中の人物を見分けてスライドショーを再生するアプリです。

写真・顔の特徴量・人物情報といったセンシティブなデータは、すべて利用者のデバイス内のみで処理・保存し、外部のサーバーへ送信しません（完全オンデバイス処理）。

2. 取得・処理する情報と利用目的

2-1. 写真・ビデオ（写真ライブラリ）

  • 目的: スライドショーの再生、および写真に写る人物を見分けるための顔の検出・分類。
  • 取り扱い: 利用者が許可した写真のみにアクセスします。写真そのもの、および写真から生成した顔の特徴量（フェイスプリント）はデバイス内のデータベースに保存され、外部へ送信されることはありません。顔の検出・特徴量の生成・人物のグループ化は、すべて Apple の Vision フレームワークおよび同梱の機械学習モデルによりデバイス上で実行されます。
  • Apple Watch との同期: 利用者がアプリ内で明示的に同期を実行した場合に限り、現在のクイック再生条件から最大48枚の圧縮した縮小コピーと、表示用の撮影日・命名済み人物名を、ペアリング済み Apple Watch 内の「ヒトコマ」へ保存します。元の高解像度写真、写真ライブラリ内の識別子、位置情報、顔の特徴量は Apple Watch へ転送しません。転送は iPhone と Apple Watch の間で Apple の WatchConnectivity を通じて行われ、当方のサーバーを経由しません。

2-2. 顔の特徴量・人物情報（生体情報に相当）

  • 目的: 同じ人物の写真をまとめ、人物ごとのスライドショーを作るため。
  • 性質: 写真から生成する顔の特徴量（フェイスプリント）は、個人を識別しうる生体情報に相当する情報です。本アプリは初回のご案内画面でこの点をお伝えしたうえで、同意（スキャンの開始）を得てから生成します。
  • 取り扱い: 顔の特徴量、利用者が付けた人物名、人物のグループ分けはデバイス内にのみ保存します。外部送信・第三者提供は一切行いません（広告事業者・解析事業者を含みます）。人物の識別は推定であり誤りを含み得るため、本アプリ内で手動修正・除外ができます。
  • 削除: 本アプリの「設定」タブ →「プライバシー」→「顔・人物データをすべて削除」から、検出済みの顔・登録した人物・スキャンの進捗をいつでもすべて削除できます（写真そのものには影響しません）。

2-3. 位置情報

  • 写真の位置情報: 写真に記録された撮影位置を、地名（都道府県・地名）の表示や場所による絞り込みに利用します。地名への変換には Apple の逆ジオコーディング（CLGeocoder）を利用するため、この処理の範囲で座標が Apple に送信されます。
  • 現在地: 設定で「現在地」「地図」の表示を有効にした場合に限り、利用中の位置情報（WhenInUse）を取得します。
  • 地図の表示: 設定で「地図（現在地）」の表示を有効にした場合に限り、再生画面に現在地のミニマップを表示します。地図の描画には Apple の地図サービス（MapKit）を利用するため、地図タイルの取得にあたり表示範囲（現在地周辺の座標）が Apple に送信されます。

これらの位置情報を当方が収集・保存・第三者提供することはありません。

2-4. 利用状況データ（アクセス解析）

  • 目的: 不具合の把握と機能改善のための、利用状況の統計的な把握。
  • 取り扱い: Google の「Google アナリティクス for Firebase（Firebase Analytics）」を利用し、アプリの起動・再生・スキャン完了などのイベントと、その粗い件数・所要時間・端末／OS の一般的な情報を送信します。
  • 送信しない情報: 写真、顔の特徴量、人物名、位置情報、その他個人を特定し得る情報は Firebase Analytics に一切含めません。送信する件数はおおまかな区分（例:「50〜199」）に丸めており、個人の特定には用いません。

Firebase Analytics の詳細は、Google のプライバシーポリシーをご参照ください。

2-5. 不具合情報（クラッシュレポート）

  • 目的: アプリが強制終了した場合や、内部で処理に失敗した場合の原因調査と修正。
  • 取り扱い: Google の「Firebase Crashlytics」を利用し、強制終了時の記録（クラッシュの発生箇所を示すプログラム上の位置情報であるスタックトレース）、端末の機種・OS バージョン・アプリのバージョン、および処理に失敗した箇所のあらかじめ定めた区分名（例:「写真の読み込み」「顔のスキャン」）を送信します。
  • 送信しない情報: 写真、顔の特徴量、人物名、位置情報、ファイル名や写真の識別子は一切含めません。エラー情報は、内部の分類コードだけを残すよう加工したうえで送信しており、自由入力の文字列や写真に関する情報が混入しない仕組みにしています。

Firebase Crashlytics の詳細は、Google のプライバシーポリシーをご参照ください。

2-6. 表示設定の遠隔切り替え（リモート設定）

  • 目的: 不適切な広告が報告された場合などに、アプリの更新（審査）を待たずに広告の表示を停止するなど、表示に関する設定を安全に切り替えるため。
  • 取り扱い: Google の「Firebase Remote Config」を利用し、当方が設定した表示用の設定値をアプリが受け取ります。この機能で利用者の情報を送信することはありません。設定値を受け取れない場合も、アプリに内蔵された既定の設定でそのまま動作します。

2-7. 広告

  • 目的: 本アプリの運営費用をまかなうための広告の表示。
  • 取り扱い: 広告の配信・最適化に Unity Technologies の「Unity LevelPlay（ironSource）」を利用します。広告の表示・計測のため、広告識別子（IDFA）や端末・ネットワークに関する一般的な情報が広告事業者に送信される場合があります。
  • トラッキングの許可: IDFA を用いたパーソナライズ広告には、iOS の「トラッキングの透明性（ATT）」による許可が必要です。許可しない場合も広告は表示されますが、利用者に最適化されない広告になります。許可は iOS の「設定」アプリからいつでも変更できます。
  • オンデバイス処理との関係: 写真・顔の特徴量・人物名・撮影位置といったセンシティブなデータを広告事業者へ渡すことはありません。

Unity LevelPlay の詳細は、Unity のプライバシーポリシーをご参照ください。

2-8. 広告の除去（アプリ内課金）

  • 目的: 広告を非表示にするための、買い切り（一度きり・サブスクリプションではありません）のアプリ内購入の提供。
  • 取り扱い: 購入・決済は Apple（App Store）が処理し、当方はクレジットカード番号などの決済情報や、利用者個人を特定する情報を取得・保存しません。広告除去を購入済みかどうかの判定は、Apple の StoreKit を通じてデバイス内で行います。

2-9. お問い合わせ

  • 目的: ご質問、不具合の報告、ご意見・ご要望への対応、および本アプリの改善。
  • 取り扱い: アプリ内のお問い合わせフォームから、利用者が入力した本文・お問い合わせの種類・任意の返信先メールアドレスを Google の Firebase Cloud Functions 経由で Cloud Firestore へ送信します。返信先を入力しない場合、個別の返信は行いません。
  • 任意の端末情報: 不具合のお問い合わせでは、利用者がフォーム上のスイッチを有効にしている場合に限り、アプリのバージョン、iOS のバージョン、端末の機種、アプリの表示言語を添付します。
  • 送信しない情報: 写真、顔の特徴量、人物名、位置情報、写真の識別子、アプリの操作ログは自動的に添付しません。これらの情報を本文へ入力しないよう、送信画面でも案内します。
  • 保存期間: 送信されたお問い合わせは受付から180日間保存し、その後 Cloud Firestore の TTL により自動削除します。広告配信、トラッキング、利用状況の分析には使用しません。
  • 下書き: 入力途中または送信に失敗した内容は利用者のデバイス内だけに保存し、送信成功時に削除します。未送信の下書きは7日後に失効します。

3. 第三者提供・データの送信先

送信先 送信される情報 目的
Google（Firebase Analytics） 匿名の利用状況イベント・粗い統計・端末／OS 情報 利用状況の分析・機能改善
Google（Firebase Crashlytics） 強制終了時の記録（スタックトレース）・端末／OS／アプリのバージョン・失敗箇所の区分名 不具合の原因調査と修正
Google（Firebase Remote Config） 設定値の受信に必要な端末・アプリの一般的な情報 広告表示の停止など、表示設定の遠隔切り替え
Google（Firebase Cloud Functions / Cloud Firestore / App Check） お問い合わせ本文・種類・任意の返信先メールアドレス・利用者が添付を選んだ端末情報 お問い合わせの受付・対応、不正送信の防止
Apple（CLGeocoder / MapKit） 現在地または写真の座標 地名への変換・地図の表示
Unity（Unity LevelPlay / ironSource 広告） 広告識別子（IDFA）・端末／ネットワークに関する一般的な情報・広告の表示／操作データ 広告の配信・計測

上記以外に、利用者の情報を第三者へ提供・販売することはありません。写真・顔の特徴量・人物名・撮影位置などのセンシティブなデータを、広告を含むいずれの第三者へも提供することはありません。

各社のプライバシーポリシー：

  • Google: https://policies.google.com/privacy
  • Apple: https://www.apple.com/legal/privacy/
  • Unity: https://unity.com/legal/privacy-policy

4. データの保存と削除

  • 顔の特徴量（生体情報に相当）・人物情報・各種設定はデバイス内にのみ保存され、当方のサーバーには一切保管されません。
  • 顔・人物データはいつでも全部削除できます: 本アプリの「設定」タブ →「プライバシー」→「顔・人物データをすべて削除」。写真ライブラリへのアクセスを保ったまま、スキャン結果だけを消せます。
  • Apple Watch に同期した縮小写真は、iPhone の「再生」タブ →「Apple Watch」→「Apple Watchから写真を削除」から削除できます。iPhone 上の元写真には影響しません。
  • 本アプリを削除すると、これらのデバイス内データも削除されます。
  • お問い合わせの下書きは端末内に最大7日間保存し、送信成功時または期限到来時に削除します。
  • 送信済みのお問い合わせは Google Cloud 上に180日間保存し、期限到来後に自動削除します。
  • 写真ライブラリへのアクセス許可は、iOS の「設定」アプリからいつでも変更・取り消しできます。

5. 子どものプライバシー

本アプリは特定の年齢層を対象としたものではなく、年齢に関する情報を収集しません。

6. 本ポリシーの改定

本ポリシーは、必要に応じて改定することがあります。重要な変更がある場合は、本ページ上で告知します。

7. お問い合わせ

8. 外部送信に関する公表（電気通信事業法第 27 条の 12）

本アプリは、機能提供、品質改善、広告表示およびお問い合わせ対応のため、利用者の端末から外部の事業者へ次の情報を送信します。

8.1 Firebase Analytics（Google LLC）

  • 送信される情報: アプリ内イベント（起動・再生・スキャン完了等）、その粗い件数・所要時間、端末情報（OS バージョン、端末モデル、言語設定）
  • 送信目的: アプリの利用状況の解析、品質改善
  • 送信しない情報: 写真、顔の特徴量、人物名、位置情報その他個人を特定し得る情報
  • プライバシーポリシー: Google のプライバシーポリシー
  • 送信の停止方法: 本アプリの設定画面にある「匿名利用状況データ共有」をオフにすることで送信を停止できます

8.2 Firebase Crashlytics（Google LLC）

  • 送信される情報: スタックトレース、端末の機種・OS バージョン・アプリのバージョン、処理に失敗した箇所のあらかじめ定めた区分名
  • 送信目的: 強制終了や処理失敗の原因調査と修正
  • 送信しない情報: 写真、顔の特徴量、人物名、位置情報、ファイル名、写真の識別子、自由入力の文字列
  • プライバシーポリシー: Google のプライバシーポリシー

8.3 Firebase Remote Config（Google LLC）

  • 送信される情報: 設定値の受信に必要な端末・アプリの一般的な情報
  • 送信目的: 広告表示の停止など、表示設定の遠隔切り替え
  • プライバシーポリシー: Google のプライバシーポリシー

8.4 Firebase Cloud Functions / Cloud Firestore / App Check（Google LLC）

  • 送信される情報: お問い合わせ本文・種類・任意の返信先メールアドレス、および利用者が添付を選んだ場合のアプリ／OS バージョン・端末機種・表示言語
  • 送信目的: お問い合わせの受付・対応、不正送信の防止
  • 保存期間: 送信されたお問い合わせは受付から180日間
  • プライバシーポリシー: Google のプライバシーポリシー

8.5 Unity LevelPlay（ironSource）（Unity Technologies）

  • 送信される情報: 広告識別子（IDFA。ATT で許可した場合のみ）、端末・ネットワークに関する一般的な情報、広告の表示・操作データ
  • 送信目的: 広告の配信・計測・最適化
  • プライバシーポリシー: Unity のプライバシーポリシー
  • 送信の制御方法: iOS の「設定」→「プライバシーとセキュリティ」→「トラッキング」から本アプリのトラッキングをオフにできます。トラッキングを許可しない場合も広告自体は表示されますが、パーソナライズされません

8.6 Apple（CLGeocoder / MapKit）

  • 送信される情報: 現在地または写真の撮影座標
  • 送信目的: 地名への変換、簡易マップの表示
  • プライバシーポリシー: Apple のプライバシーポリシー

8.7 本ページのアクセス解析

本ページの閲覧時には、サイトの利用状況を把握するため Google Analytics を使用し、閲覧ページ、アクセス日時、端末・ブラウザの一般的な情報等を Google LLC へ送信する場合があります。本アプリ内の写真、顔の特徴量、人物名、位置情報は含まれません。詳細は、Google のプライバシーポリシーをご参照ください。

8.8 公表の更新

本公表内容は、外部送信先または送信内容に変更があった場合、速やかに更新します。
